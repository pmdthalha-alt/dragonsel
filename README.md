# Dragonsel

Dragonsel is an all-in-one AI creation workspace for research, writing, design, video, websites, apps, games, and export.

## Current Strategy

Dragonsel is completely free during early access.

The priority right now is:

- Build the best product possible
- Grow users fast
- Make people love the platform
- Create strong word-of-mouth
- Improve retention
- Build trust
- Gather feedback
- Make Dragonsel addictive and useful

## What Dragonsel Includes

- Dragonsel Studio: main project dashboard
- Dragonsel Write: notes, documents, research, summaries, source uploads
- Dragonsel Design: brands, posters, thumbnails, social assets, slides
- Dragonsel Video: timelines, captions, clips, reels, launch videos
- Dragonsel Web: landing pages, sections, CMS-style content, publish flows
- Dragonsel App: no-code app, tool, form, portal, and dashboard builder
- Dragonsel Game Lab: game concepts, menus, loops, assets, prototypes
- Dragonsel Export: share links, downloads, live presentation, launch packages

## Product Inspiration Direction

Dragonsel should not copy another product's brand or exact screens. The current direction combines useful workflow patterns into an original product:

- Source-grounded research and study workflows
- Editable visual design and brand systems
- AI-assisted video timelines and caption workflows
- Prompt-to-site and prompt-to-app generation
- One shared project brain that connects every output
