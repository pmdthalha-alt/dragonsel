# Dragonsel Rebuild Plan - Apple-Level Creative AI Platform

## VISION
Recreate and improve the core working systems of Canva, CapCut, NotebookLM, and Base44 in one connected platform with Apple-level design.

## PHASE 1: Core Architecture

### 1.1 Unified App Shell
- Main AI chatbot entry point
- Smart workspace routing
- Project brain system
- Universal save/load

### 1.2 Design System
- Premium color palette
- Typography scale
- Spacing system
- Animation library
- Component library

### 2.1 Design Editor
- Canvas workspace (Fabric.js)

- Image upload
- Layer management
- Templates
- Brand kit
- Export (PNG, JPG, PDF)

### 2.2 Slides Editor
- Multi-page deck
- Slide navigator
