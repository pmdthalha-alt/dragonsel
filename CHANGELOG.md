# Dragonsel Changelog

- Removed monetization-focused sections from the active website.
- Replaced paid conversion messaging with free early-access messaging.
- Added Free Beta badge inside the product mockup.
- Added no-credit-card messaging.
- Added referral and invite growth system section.

- Added Roadmap / Why Free Beta section.

### Product Strategy

Phase 1 is free growth mode:

- Build product love
- Grow users
- Improve retention
- Collect feedback
- Encourage sharing
- Build trust

Phase 2 can explore optional advanced features later, but no payment system is part of the current website build.
